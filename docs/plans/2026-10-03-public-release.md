## 使用

把 `ccode.exe` 放到可写目录，运行 `ccode.exe --help` 或 `ccode.exe --version`。
API 调用需要在本机设置 `A_BASE_URL` 和 `A_API_KEY` 或 `A_AUTH_TOKEN`，不要把凭证写入
公开日志、截图或 issue。本版采用 API 凭证模式，不提供浏览器登录。

使用 `--workspace PATH` 选择项目；使用 `--data-dir PATH`（或 `CCODE_DATA_DIR`）指定
持久数据目录。未指定时使用 exe 旁的 `data\cc`。配置、会话、缓存与运行时应按完整目录
保留；移动程序时不要丢弃原有数据。首次使用先在独立数据目录验证自己的 API 服务。

更新前退出所有实例，备份完整数据目录并保留旧 exe；不要删除 profile 来解决问题。
本版提供 `--snapshot-profile` 及显式验证/激活的升级回滚命令，详见 `--help`。
回退程序与回退会话数据不是同一件事，勿让旧版本直接覆盖唯一的数据副本。

## 已知限制与未完成项

- `https://` 代理访问 HTTPS API：按使用者要求暂缓，本次不承诺支持；不是验收通过。
- HTTPS 代理至 HTTP 目标：当前代码返回 `E_NETWORK`，属于仍待修复的已知缺口，
  不是上述暂缓授权的延伸，也不记录为通过。该路径不适合使用此版本。
- Hosted 用例使用真实引擎/工具与确定性的 loopback 模型响应，不等于任意企业 API 服务均已验证。
- 企业正式信任、签名部署/更新、企业包通知材料审批及名称政策未完成；普通版发布不改变这些状态。
